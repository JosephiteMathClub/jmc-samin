## 📌 Overview

The **Josephite Math Club (JMC)** is the premier mathematics club of **Saint Joseph Higher Secondary School**, Dhaka — the first of its kind at the institution. Founded in **2015**, JMC was established to cultivate a love for analytical thinking, promote mathematical excellence, and prepare students for national and international olympiads.

This repository contains the source code and assets for the **official JMC website**, hosted at [jmc-sjs.org](https://jmc-sjs.org). The platform serves as a central hub for club news, challenge problems, events, notices, workshops, and community engagement.

---

## ✨ Features

- 🏠 **Dynamic Landing Page** — Animated mathematical sanctuary introduction with live club updates
- 📢 **Notices & Announcements** — Real-time club news, event schedules, and important updates
- 🧩 **Challenge Problems** — Curated math problems for olympiad training and self-study
- 📅 **Events** — Coverage of workshops, competitions, seminars, and inter-school programs
- 🏆 **Achievements** — Showcase of member accomplishments and club milestones
- 👥 **Panel & Team** — Profiles of the current executive and academic team
- 🔍 **SEO Optimized** — Proper meta tags, Open Graph, and Twitter card integration
- 📱 **Responsive Design** — Fully optimized for desktop and mobile devices

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/JosephiteMathClub/jmc-samin.git

# 2. Navigate into the project directory
cd jmc-samin

# 3. Install dependencies
npm install
# or
yarn install
```

### Running Locally

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the site.

### Building for Production

```bash
npm run build
npm run start
```
